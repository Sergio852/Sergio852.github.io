## De qué trata

En esta práctica se instala y configura un servidor SSH en Debian
para permitir el acceso remoto desde otro equipo de la red.

## Objetivos

- Instalar OpenSSH Server.
- Crear usuarios para el acceso remoto.
- Comprobar el estado del servicio.
- Realizar una conexión mediante SSH.
- Aplicar medidas básicas de seguridad.

## Procedimiento resumido

Se instala el paquete OpenSSH Server y se comprueba que el servicio
está activo. Después se crea un usuario y se prueba el acceso desde
un segundo equipo utilizando su dirección IP.

## Conclusión

Esta práctica permite comprender el funcionamiento de SSH y su
importancia en la administración remota de servidores Linux.

## Tecnologías utilizadas

- Debian
- OpenSSH
- Bash
- VirtualBox
